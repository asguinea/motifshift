# Security

MotifShift is a local command-line research tool. Experiment execution uses
synthetic data and requires no accounts, credentials, external datasets, or network
services. Installing dependencies requires access to a package index unless cached.

Treat configurations and output paths as trusted local inputs. Run untrusted forks
in an isolated environment. Run manifests contain configuration values and installed
package versions; inspect them before sharing.

For a security issue, use the repository's **Security → Report a vulnerability**
feature when available. Avoid posting credentials or exploit details in public
issues. No response-time or long-term support guarantee is offered.
